## エンジニア課題_石崎花栞

### マージソート
安定ソートかつ平均・最悪計算時間がともに O(n log n) で、入力データの順番にかかわらず安定した計算量で動作する点が好きです。
結合用の追加メモリが必要になる点には注意が必要ですが、今回の実装では、同じ年齢の社員の元の順序を保ったまま並べ替えられるところが実用的でよいと思います。

### クイックソート
不安定ソートですが、平均計算時間が O(n log n) であり、追加のメモリを抑えて動作する点が好きです。
最悪の場合、計算時間がO(n²) になってしまう注意点がありますが、プリミティブ型などの同じ値のデータの順番を気にしないものの並び替えには使いやすくよいと思います。

### 実装
Java 21

### 実行方法
```sh
javac -encoding UTF-8 -d _out Main.java Test.java merge/*.java quick/*.java
java -cp _out Main
java -cp _out Test
```
